# what is a computer?

   A computer is a machine that: Receives input --> Processes data --> stores data --> produces output.

   ##### Example: 
             Keyboard Input
                  ↓
                 CPU
                  ↓
            RAM ↔ Storage
                  ↓
            Monitor Output

  ##### For DevOps: 
               User Request
                    ↓
                Web Server
                    ↓
                Application
                    ↓
                 Database
                    ↓
                Response

A server is simply a computer designed to provide services to other computers.
